## 全部示范的复查与第二轮修复

72 条示范的首/中/尾双视角原图、角色叠图已逐条浏览；另查看每条中段的 RGB、光流、深度、UVD 四联图。保存于 `evidence/raw_overview`、`geometry_overview`、`flow_overview`。

1. 抽屉闭合与部分中段仍有 SAM 漏检。对 6 条相关抽屉记录逐个当前帧重新提示，使用 wooden box 与固定目标框。
2. 5 条堆叠记录存在少量红方块漏检，另有一帧机器人漏检。当前帧重新分割；单红方块场景用红色连通区域提供紧框与边缘支持，避免把夹爪当成红方块。抽屉与堆叠 11 条记录修复 42 个提示帧。全部修复叠图已检查，见 `evidence/mask_repairs/full_*.jpg`。
3. 纸盒任务的通用 block 提示会在物体入盒后漂移到纸盒。14 条重新使用 cardboard box + red cube，其中实测黄方块的一条使用 yellow cube；纸盒与方块使用独立提示，单实例编号固定。复查中，方块完全入盒后，跟踪器仍偶尔转向同场景纸盒；两者都属于模型所用的物体角色，最终前景/角色合并结果与画面对应。实例级诊断记录保留。
4. SAM 的临时实例编号及类别漂移会截断正确的物体运动。真实数据有效性改为：图像内、起终点深度有效、RAFT 前后向误差 <1 px、起终点角色一致（本体或物体）。几何对应由光流与深度建立，SAM 实例编号保留用于诊断；`sam_id_disagreement_pixels` 记录编号变化的影响。这是本轮真实数据处理选择。
5. 深度单位、UVD 正负方向、宽度归一化和编码沿用作者实现。已知平移 (+8, −4) px 的 RAFT 核验：中位误差 0.057 px，P90 0.124 px；已知 +0.02 m 深度变化及 mu-law 量化检查通过。

修复后的几何与 latent 使用输入内容签名重建，旧 latent 目录保留。全量验收将再次逐窗口读取并记录最终清单哈希。
