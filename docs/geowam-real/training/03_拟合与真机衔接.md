# 怎样看拟合，以及怎样接真机

## 已完成的离线检查

每个检查点固定五个训练窗口，每任务一个，固定采样种子 1234。每个窗口预测六关节＋夹爪的完整 32 步，以及全部 9 帧 RGB／Track。

- `*_physical_actions.png`：7 维逐时刻预测与记录；看方向、幅度和夹爪切换。
- `scalars.json`：关节 MAE（rad）、32 个时刻的夹爪开合匹配率、RGB／Track latent MSE。
- `*_decoded.jpg`：记录与预测的 RGB／Track 对照。
- `*_video_pred_strip.png` / `*_track_pred_strip.png`：全部 9 帧预测。

解码在 CPU 执行，两卡继续训练：

```bash
CUDA_VISIBLE_DEVICES= envs/preprocess/bin/python repos/UR5e-RoboTwin-Real/scripts/geowam/decode_fit_predictions.py --step 8997
```

首帧为当前条件；主要观察后续动作、运动和物体位置。结果汇总见 [固定窗口拟合检查](../13_固定窗口拟合检查.md)。这些数值衡量训练片段拟合，真机成功率由闭环试验记录。

## 下一阶段

1. 到预定步数后，扩展至各任务多个 episode 的起始／中段／结束窗口。
2. 根据动作与夹爪曲线、几何预测选择检查点，决定是否小学习率续训。
3. 真机主机复用相同 RGB 布局、当前 mask／depth 预处理、状态归一化与关节增量还原。
4. 测量实时分割与模型推理耗时，确定动作块执行与重规划频率，再做各任务闭环执行。

当前单帧条件与训练缓存的一致性、原生离线采样已经跑通。实时 mask 服务、控制接口和闭环结果在迁移真机阶段落实。
