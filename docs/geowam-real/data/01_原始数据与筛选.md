# 原始数据与筛选

## 输入

数据仓库：[data_ur5e_gwam](https://github.com/Yutenji-Nyamu/data_ur5e_gwam)。Git 保存任务索引、动作与同步 CSV、相机元数据和预览；10 月 6／7 日 Release 保存原始 RGB／深度图像。服务器恢复到 `data/raw/日期/任务/episode/`。

每条包含 head／wrist RGB、对齐深度、`action.csv`、`sync.csv` 和夹爪事件；相机深度单位保存在 `images/camera_calibration.json`。训练几何采用 head 深度；wrist 提供 RGB。

## 筛选

| 类别 | 条数 | 处理 |
|---|---:|---|
| 普通 RGB-D | 72 | 训练 |
| 桌布 OOD | 5 | 独立留存 |
| 彩色光照 OOD | 5 | 独立留存 |
| 其余缺深度 | 5 | 排除 |

原始库共 87 条、80 条有深度。7 条缺深度中有 2 条已归入 OOD，因此上表四组互斥。实际训练 72 条均有实测深度。

任务与数据量：抽屉 16、纸盒 14、分拣 14、堆叠 13、插充电器 15。实际堆叠是红方块放在黄方块上。训练语言与单臂接口按实际数据确定。

## 输出与入口

- 清单：`data/manifests/train_rgbd.jsonl`、`ood_tablecloth*.jsonl`、`ood_lighting*.jsonl`、`excluded_no_depth.jsonl`。
- 统计：`data/manifests/summary.json`。
- 策略：[episode_policy.json](../../../configs/geowam/episode_policy.json)。
- 脚本：[build_episode_manifest.py](../../../scripts/geowam/build_episode_manifest.py)、[audit_recordings.py](../../../scripts/geowam/audit_recordings.py)。

72 条用于此次训练拟合。闭环评估在后续真机运行中另行收集。
