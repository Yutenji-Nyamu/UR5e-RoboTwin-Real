## 技术决策与可自动调整项

- 基于已锁定 RoboTwin `210720340637cb4619283b295dde4cdd807c9e66`，优先原生 JAX/Flax trainer；不再为了未来 RLT 优先改 RLinf/LeRobot 训练后端。
- 同包 `actual_q + actual_TCP_pose + timestamp` 双记录；不要分别查询后按行号拼接。旧 API 保持兼容。
- 首版外部绝对关节位置、内部原生 delta-joint 变换；`adapt_to_pi=False`，重算本机数据统计。训练和推理共享变换。
- 建议先沿用 14D 兼容封装 `[q6,0,q6,g]`，内部 pad32；物理执行固定取第一组 q6 与第13列夹爪。不是必须双臂，也不是动作空间由 shape 决定。
- 新 joint executor 直接 servoJ；现有 TCP executor 继续通过 IK，不能共用一个未标注空间的“六维目标”入口。
- batch、step 预算、H/K、学习率、软件限速等使用 [主规划](README.md) 初值，按检查结果调整，不另做大规模参数搜索。
- 新数据建议先 5 条成功；当前没有为泛化留出数据的硬要求。
