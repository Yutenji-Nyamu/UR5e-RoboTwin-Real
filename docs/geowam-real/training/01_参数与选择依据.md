# 参数怎样选择

正式配置：[train_rgbd72.yaml](../../../configs/geowam/train_rgbd72.yaml)。

| 参数 | 选择 | 理由 |
|---|---|---|
| GPU | 深圳 2 机物理 6／7，两张 H100 80 GB | 使用已交接的两卡 |
| 并行 | block FSDP2，BF16，梯度检查点 | 分担模型／优化器状态，并节约激活显存 |
| Batch | 每卡 2，全局 4，累积 1 | batch 1／2 短测后采用，正式运行稳定；详见性能复核 |
| 步数 | 30,000 | 约 120,000 个窗口采样，约总窗口量 50 次 |
| 任务采样 | 五任务等权 | 平衡不同任务记录长度 |
| 保存 | 每小时，保留最近 3 个完整检查点 | 持续拟合对照和恢复 |
| 推理轮数 | 16 | 使用作者原生异步采样 |

## 学习率

| 分组 | 初始学习率 | 冻结／渐增 |
|---|---:|---|
| Video | 1e-6 | 冻结 500 步，渐增 1,000 步 |
| Track | 1e-5 | 渐增 500 步 |
| Action | 2e-5 | 冻结 100 步，渐增 500 步 |
| Focus／读取 | 1e-4 | 直接学习 |
| 状态编码 | 3e-6 | 冻结 100 步，渐增 500 步 |

已有视频先验小步调整，新增读取模块学习更快。第 3,000 步开始余弦衰减，30,000 步时到初始值的 0.1 倍。AdamW 参数、模态噪声混合、dropout 和辅助目标见配置；weight decay 0.01、betas 0.9／0.95、梯度裁剪 1.0。

通过每卡 batch 1／2 短测、step 2 完整保存／恢复到 step 3、五任务原生推理后启动。短测分别只有几步，且清单／worker 数有差异，主要验证训练与恢复流程。2026-10-10 12:55 复核：最近 1,000 步平均约 2.96 秒／步（含保存等跨日志开销），nvidia-smi 每卡使用约 69.6 GiB，实际空闲约 9.6 GiB。详见 [数据体积与训练性能](../17_数据体积与训练性能.md)。

这些是参考作者配置与两卡实测确定的首轮设置。30,000 步完成后根据多任务、多阶段拟合决定续训步数与更小学习率。
