# 模块初始化与训练顺序

依据 Gitee `1392ab5` 的 `metiswam4d/build.py`、初始化实现及 `data/contract.py`，结合 Alpha-Franka safetensors 头部，已执行 meta-device 形状审计。完整结果：workspace `evidence/initialization_shapes.json`。

## 各部分从哪里来

| 模块 | 初始化来源 | 核对结果 |
|---|---|---|
| Video，3072 维 / 30 层 | OpenWAM Alpha-Franka 的 `video_backbone.dit` | 825 个源张量全匹配；新增 demo embedding 按源码置零 |
| Action，1024 维 / 30 层 | Alpha `action_backbone`，复用项目重命名 | 824 个源张量全匹配 |
| Proprio，80→4096 | Alpha `proprio_encoder` | 2 个张量全匹配 |
| Track，1024 维 / 20 层 | `interpolate_from_video` | 201 个同形复制、354 个插值、2 个条件派生、23 个新增 |
| 当前 RGB/depth/mask 条件 | 复用插值后的 patch 权重，按源码平铺缩放 | 新增条件混合/角色/相机参数随训练学习 |
| Focus / Reader / 进度头 / 本体 embedding | 项目原生初始化 | 通过机器人轨迹和几何监督学习 |
| Wan VAE，48 通道 | Wan2.2-TI2V-5B-Diffusers 的 VAE | 冻结；离线生成视觉缓存 |
| UMT5 / tokenizer | 同一官方 Wan Diffusers 版本 | 冻结；离线文本缓存 |
| SAM 3.1 / RAFT | Meta 权重魔搭镜像 / torchvision 官方权重 | 数据预处理阶段使用 |

完整策略约 6.753B 参数。Video 在 Alpha 内已经由 Wan2.2 初始化并经过机器人数据训练，因此先完整继承 Alpha Video。VAE 和文字编码器单独取 Wan 配套文件。

Track 从 30 层映射到 20 层：索引为 `round(i*29/19)`，通道轴从 3072 插值至 1024。新条件、角色、相机参数与 Reader 等遵循项目定义。审计目前验证张量名称、形状和转换数量；下载后追加实际加载、有限数值与前向/反向检查。

## UR5e 动作接口

Alpha-Franka 为 EEF10，内部槽位 0–9；现有 UR5e 适配器为 6 关节加 1 DOF gripper，内部槽位 10–16。先沿用已经对接机器人的 joint7 路径：未来关节相对当前关节的变化＋绝对夹爪命令，重新统计训练 episode 的归一化与有效维度 mask。

这一步负责把通用动作参数适配到本台 UR5e。重点检查有效槽位、单位、夹爪方向、归一化/反归一化和输出转换。已有适配器为 10 Hz / H50 的 RGB→Action；完整三专家独立接 H32，覆盖 3.2 秒。

## 全模态样本

- `video_clean [48,3,24,20]`；两视角合图的具体布局固定后同步训练/推理。
- `track_clean [48,3,16,20]`；当前 `rgb_condition/depth_condition/mask_condition` 各 `[48,1,16,20]`。
- `action [32,80]` 与有效维度 mask；`proprio [1,80]`。
- `text_context [L<=512,4096]`、embodiment、episode/window key。
- Track 有效区、角色及 8 个时间段的位移辅助监督按 contract 写入；固定主相机 camera delta 为零。

## 训练推进

1. 下载校验完成后，用真实权重做载入报告；新增参数与已载入参数分别列出。
2. 一条真实 episode 检查动作反归一化、几何缓存和一次前向/反向；短过拟合确认损失随更新变化。
3. 先完成现有 RGB→Action 的数据/服务闭环，再接完整三专家和读取模块；用同一条示范比较动作与未来预测预览。
4. 两张 H100 从 BF16、梯度检查点、每卡 batch=1、梯度累积和 FSDP 起步，测量显存、step 时间，再定正式更新预算。
5. 用确认的五任务训练列表运行正式微调；保存模型、动作统计、相机合图、mask 提示、频率与 chunk 配置。
6. 服务器离线回放观测，调用与现场一致的策略服务，核对返回动作形状、单位、延迟和时间窗；随后迁移现场做闭环执行。

模板 `configs/stage3_real_ur5e.yaml` 仍写双臂/14 维与作者路径，本项目单臂配置需要重填。初始化路径指向本次 Alpha 文件，作者 S2 路径和自动 resume 按新实验目录整理。新增可选 IFP 模块默认关闭，优先完成主三专家流程。

Q3 人类演示接口在最新 Gitee 另有更新；其训练/推理路线与本轮机器人 RGB-D 数据处理分别记录。论文与 Overleaf 本轮保持原稿。
