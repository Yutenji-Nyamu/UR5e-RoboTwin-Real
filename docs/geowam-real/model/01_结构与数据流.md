# 模型结构与数据流

## 三个专家怎样分工

| 部分 | 学习对象 | 约参数量 |
|---|---|---:|
| Video expert | 未来画面怎样变化 | 50.00 亿 |
| Track expert | 前景几何运动怎样变化 | 6.89 亿 |
| Action expert | 机器人未来怎样运动 | 10.21 亿 |
| Focus／读取等 | 哪些空间、时间信息对当前动作有用 | 0.44 亿 |
| 状态编码 | 当前机器人状态 | 0.003 亿 |

合计约 67.54 亿。冻结 VAE 和文本编码器先产生缓存，主要训练计算在三专家和读取模块中。

## 一次训练

读取同一片段的 RGB、Track、动作及当前条件 → 按作者噪声混合给各模态加入相应噪声 → 联合预测并计算视频、运动、动作及辅助损失 → 更新三专家和新模块。

动作读取模块结合当前条件，从世界表示中取出任务相关的空间／时间信息。`video_window` 对准拼图上半部主视角；Track 使用主视角几何。前 3,000 步按作者机制从 dense 读取过渡到 compact。

## 一次离线推理

当前双视角 RGB、主相机深度／mask、当前状态、任务指令 → 16 轮原生异步采样 → 未来 RGB、Track 和 32 步动作。未来记录用于对照拟合结果。

当前训练覆盖五个机器人任务。Q3 人类演示配对、适配和视频条件接口属于后续单独实验安排。
