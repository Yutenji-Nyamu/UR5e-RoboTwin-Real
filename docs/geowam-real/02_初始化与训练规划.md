# 模块初始化与训练规划（初步代码核查）
| 模块 | 来源与方式 |
|---|---|
| Video expert | 指定OpenWAM Alpha-Franka的video_backbone.dit；本身就是Wan2.2 TI2V-5B，3072维30层 |
| Action expert | Alpha action_backbone，1024维30层；沿用项目重命名映射 |
| proprio | Alpha proprio_encoder，80→4096 |
| Track expert | 项目interpolate_from_video，Video的30层映射到20层，宽度3072→1024插值 |
| Track condition stem | 项目用插值后的patch embedding平铺到RGB/depth/mask条件分支 |
| 读取、进度、本体等新增模块 | 遵循源码初始化，再通过真机监督学习 |
| VAE / text | Wan2.2 TI2V-5B Diffusers；冻结离线编码，缓存文本与视觉潜变量 |
| SAM3.1 / RAFT | 离线处理模型，独立于策略训练参数 |

Alpha-Franka动作是EEF10，槽位0–9，gripper=-1闭/+1开。
真机已有接口是joint7、槽位10–16，预测未来关节差与绝对夹爪命令；需沿用UR5e数据统计重新归一化，并对接动作头，验收形状与语义。
建议先正式权重加载与单episode过拟合，再加入Track与读取模块，最后五任务训练和离线动作服务。
两张H100从BF16、gradient checkpointing、batch1和梯度累积起步；实际显存/耗时测后确定FSDP及更新范围。
VAE和文本缓存可降低训练显存；Mask/RAFT逐episode处理，不必训练时重复推理。
完整训练配置需清除作者服务器的initialize_from/resume路径，采用本次初始化报告与UR5e数据路径。
