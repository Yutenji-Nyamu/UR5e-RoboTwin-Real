## 3. RGB-D 怎样变成训练数据

原始双视角 RGB ＋主相机深度＋机器人关节／夹爪记录
→ SAM 3.1 掩码
→ RAFT 双向光流
→ 三通道 Track-UVD
→ Wan VAE／文本编码器缓存
→ 训练三专家。

- **SAM 3.1：哪些像素属于机器人，哪些属于物体。** 用任务相关文字和少量框提示分出夹爪、方块、抽屉或盒子。保留本体／物体角色。
- **RAFT：这个像素移到了哪里。** 对相隔 4 个原始帧的 RGB 做前后向匹配，得到横纵位移。
- **UVD：再补上深度变化。** 在光流对应的起终点读实测深度，得到 `(横向位移／图宽，纵向位移／图宽，深度差米)`。沿用作者尺度、软阈值及 μ-law 编码。
- **过滤：只监督可靠点。** 使用图像边界、两端有效深度、前后向误差 <1 px 和本体／物体角色一致性。SAM 实例编号跳变作为诊断记录；最终角色约束对真实视频更稳定。
- **离线缓存：把耗时视觉编码提前做好。** 上方 head、下方 wrist 的双视角 RGB，与主相机 Track 分别通过冻结 VAE；五条任务指令通过冻结文本编码器。训练直接读取缓存。

几何来自固定主相机。当前 UVD 采用图像位移和实测深度差；使用相机 SDK 的 RGB／深度对齐和深度单位。该流程使用现有相机数据及机器人状态。

## 5. 动作和推理接口

以真实数据的单臂 6 关节＋1 DOF gripper 为准；10 Hz，一个动作块预测 32 步，约 3.2 秒。

六关节目标是“未来关节位置减去当前关节位置”；夹爪目标是绝对开／关命令。推理时把预测关节增量加回当前关节位置。关节做训练集 z-score，夹爪映射为 2g−1；使用作者 80 维接口中的 7 个有效槽及一个单臂本体编号。

训练片段有 9 帧视频／Track 和 32 步动作。离线推理只给当前 RGB、主视角深度和 mask、状态与指令，生成未来动作及 RGB／Track；未来记录用于拟合对照。后续真机部署需把同样的当前输入处理和动作还原接到控制端。

## 6. 每块参数从哪里来

| 模块 | 初始化 | 直观含义 |
|---|---|---|
| Video | OpenWAM-Alpha Franka 的 Wan 视频专家 | 已有机器人视频先验 |
| Action | 同一 Alpha 检查点 | 继承动作网络，再适配 UR5e joint7 |
| 本体状态编码器 | 同一 Alpha 检查点 | 继承状态输入网络 |
| Track | 作者从 Video 复制／插值的初始化实现 | 从视觉先验学习几何运动 |
| 聚焦读取、角色、进度等新增模块 | 作者默认初始化 | 在这批数据上学习 |
| VAE／UMT5 | Wan2.2 TI2V-5B 官方模块 | 冻结，提前编码图像和文字 |

总计约 67.54 亿参数。Video 实际使用 Alpha 中已有的 Wan 权重；VAE 和文本模块单独来自 Wan2.2。Alpha 原有 EEF10 动作接口与本轮 joint7 有差别，因此保留网络先验并学习新的动作／状态接口。当前初始化属于可运行的实测数据适配起点；作者专用 Track 预训练经验由本轮监督继续学习。

SAM 3.1 从 ModelScope 官方镜像取得并核对文件哈希，RAFT 使用官方 large 权重；主要权重及源码版本均记录在锁定文件和初始化报告。

## 7. 训练参数为什么这样选

| 选择 | 当前值 | 目的 |
|---|---|---|
| 两卡并行 | 物理 GPU 6／7，H100 80 GB；FSDP2 block | 两卡分担模型、梯度和优化器状态 |
| 精度／显存 | BF16＋梯度检查点 | 减少显存，换取可接受的重算 |
| Batch | 每卡 2，全局 4，累积 1 | batch 1／2 实测后选择可容纳且吞吐合适的设置 |
| 采样 | 五任务等权 | 控制长分拣轨迹对训练占比的影响 |
| 步数 | 30,000 | 约 120,000 个窗口采样，相当于总窗口量约 50 次 |
| 保存 | 每小时完整模型＋优化器，保留最近 3 份 | 支持续训和固定输入对照 |
| 推理检查 | 原生 16 轮采样、五任务各一固定窗口 | 看实际输出怎样随训练变化 |

学习率按模块设定：Video `1e-6`、Track `1e-5`、Action `2e-5`、聚焦读取 `1e-4`、状态编码 `3e-6`。已有 Video 权重小步调整，新增读取模块学习更快，Track 与动作居中。Video 先冻结 500 步，Action／状态先冻结 100 步，再渐增；3,000 步后余弦降低学习率，末尾到初始值的 10%。前 3,000 步从 dense 读取过渡到 compact，噪声混合、模态 dropout 与辅助损失沿用作者设计。

先跑短 smoke，比过 batch 1／2，验证完整检查点保存／恢复和五任务推理后正式启动。当前约 2.7 秒／步，nvidia-smi 每卡约 71 GB；全流程时间还包括保存和采样。30,000 步后根据更广泛的任务阶段拟合决定是否小学习率续训。
