# 数据处理规划（待最新 Gitee 与真实数据复核）
先盘点原始 episode，再跑每任务1条可视化样本，然后批量处理。
1. 相机原始RGB、对齐depth、时间戳、关节状态与夹爪命令一起读取。
2. 固定主相机用SAM3.1分割机械臂/夹爪和各个任务物体；保留实例ID与本体/物体角色。文字提示后检查遮挡、抓取、放下、关闭等关键帧，必要时添加点/框纠正。
3. RAFT对同一主视角t和t+4做前后向光流；在对应终点像素读取depth，得到(du,dv,dd)。先确认实际帧率；4帧在不同采样频率下代表不同时长。
4. 使用边界、有效深度、前后向一致性与同实例过滤。保留valid mask和原始浮点位移。
5. 复用Metis codec：两像素位移均除宽W，深度差米；scale=(1/6,1/6,0.10)，mu=31。深度软阈值按真实传感器噪声检查。
6. 生成RGB/mask/flow/depth/Track并列预览，再VAE编码与动作时间窗对齐。

固定主相机直接UVD不需要手眼外参。相机内参、depth_scale、对齐信息从现有录制元数据读取；如要XYZ提升或腕部相机运动补偿再使用对应相机参数。
缺depth的episode可先走RGB→Action；若加入几何训练，可用深度模型离线估计并单列来源、尺度和有效区。实测depth与估计depth分别审阅。
训练缓存按原始episode组织；模型推理所需当前RGB-D/mask也需要因果处理接口，训练监督中的未来光流仅离线使用。

当前真机适配器已实现10Hz/H50的RGB→Action；完整三专家数据适配待对接Gitee最新代码。
