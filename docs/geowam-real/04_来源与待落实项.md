# 核对来源与下一步决策

## 项目代码

- Gitee 主体：`https://gitee.com/droliven/MetisWAM4D_260921`，版本见锁文件。初始化入口 `metiswam4d/build.py`；样本布局 `metiswam4d/data/contract.py`；UVD 编码 `metiswam4d/data/rt2/codec.py`；人类视频光流/深度处理见 IG10K 预处理代码。
- 真机适配器：`src/ur5e_real/adapters/metiswam4d/`。已有 joint7、80 维槽位、数据同步及 RGB→Action 服务，完整 Track 路径继续在此基础上接入。
- 数据来源与计数：data 仓库 `index.csv`、逐 episode `session.json`、`camera_calibration.json`、`rgbd_frames.csv`；逐条汇总在 workspace `evidence/data-audit.json`。
- 稿件只读参考：附录平台、示范数量、SAM/RAFT 处理说明。当前采集进度与既定每任务 50 条目标分别记录。

## 公开原始来源

- [OpenWAM Alpha-Franka](https://huggingface.co/OpenWAM/OpenWAM-Alpha-Real-Single-Arm-Franka)：继承 Video、Action、proprio。
- [Wan2.2 TI2V-5B Diffusers](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B-Diffusers)：VAE、UMT5、tokenizer。
- [Meta SAM3 代码](https://github.com/facebookresearch/sam3) 与 [SAM3.1 官方模型](https://huggingface.co/facebook/sam3.1)。
- [SAM3.1 魔搭镜像](https://www.modelscope.cn/models/facebook/sam3.1)：服务器实测可直接下载。镜像 SHA256 构成的 LFS pointer 与官方 Git OID 一致，证据 `sam31_source_identity.json`。
- [Wan 魔搭镜像](https://www.modelscope.cn/models/Wan-AI/Wan2.2-TI2V-5B-Diffusers)：各大权重 LFS pointer 一致，证据 `wan_source_identity.json`。
- [RAFT 官方代码](https://github.com/princeton-vl/RAFT)；实际采用 [torchvision RAFT Large](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.optical_flow.raft_large.html) 配套权重，便于复用 Metis 的 torchvision 推理路径。

## 已落实的选择

使用固定 head 的实测对齐深度构建 UVD；腕部 RGB 保留为策略观察。首轮使用 SAM3.1 原版权重，增加逐任务提示与点/框修正；RAFT 保持官方权重。模型策略先继承 Alpha，Track 按作者实现插值。

## 实施时需落实

- 常规示范与桌布/光照/外观变体逐 episode 确认用途，随后生成共同训练列表。
- 固定两视角合图顺序、裁剪缩放和 mask 实例定义；更新模型输入配置。
- 用真实权重检查完整加载和 UR5e 动作槽位；重算训练统计。
- 当前因果 mask 接口、完整三专家数据集适配器和现场策略服务整合。
- 每任务先审阅一条，再处理整批；训练配置以实际显存和 step 时间确定。
