## 处理和检查做了什么

1. SAM 3.1 分出机器人和操作物体，逐条查看首／中／末帧。针对抽屉、盒子与堆叠的漏分或粘连调整提示，修复 12 条记录的 44 个提示帧；全部鞋盒记录另作专项复查。
2. RAFT 估计相隔 4 帧的双向光流，结合起终点的实测深度得到 UVD。有效点同时满足图内、有效深度、前后向一致性和机器人／物体角色一致性。
3. 真实视频的 SAM 实例编号会跳变，匹配采用稳定的角色一致性；编号差异保留为诊断量。这项适配保留机器人／物体区分，并让接触期间的有效运动得到监督。
4. 使用作者的位移归一化、软阈值、μ-law 与 Wan VAE 编码。已检查全部缓存、动作归一化往返、已知平移／深度差，以及 VAE 重建。
5. 单独使用当前观察编码，与训练缓存的当前条件完全一致；替换未来帧后当前条件仍一致。五任务原生推理、完整检查点保存与恢复均已实际跑通。

两卡 smoke 比较后采用 FSDP2 block、BF16、梯度检查点、每卡 batch 2、全局 batch 4。正式运行 `train_rgbd72_v1` 于 **2026-10-10 03:58（北京时间）** 启动，计划 **30,000 步**，约合有效窗口总量的 50 次采样；五任务等权。动作、视频分支按配置逐步打开学习率。

每小时保存完整检查点并用五个固定窗口检查拟合：六关节与夹爪的完整 32 步预测曲线、动作误差、预测 RGB 与 Track。CPU 负责视频解码，两张 GPU 持续训练。初始 smoke 预测已保存，后续用同一组样本观察改善。配置与学习率见 [训练说明](08_TRAINING.md)。
