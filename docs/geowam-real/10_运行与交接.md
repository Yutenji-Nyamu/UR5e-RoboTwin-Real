## 续训

启动器持有 `runs/training.lock`，状态保存在 `runs/training_status.json`，包含监督进程、每次启动的 PID、启动时间、GPU UUID 和日志。故障时先核对进程身份与完整检查点，再运行：

```bash
CUDA_VISIBLE_DEVICES= envs/preprocess/bin/python repos/UR5e-RoboTwin-Real/scripts/geowam/run_training.py train
```

入口自动选择最近完整检查点，保留已有输出与最多三次启动记录。数据清单、预处理配置与 QA 标记通过校验后启动。两卡固定为物理 6/7；RLT 已交接，本任务调试与恢复优先；其他卡的工作独立运行。

## 心跳停止但训练仍在推进时

先对照 `training_status.json` 中的启动记录与 `/proc` 的 PID、启动时间、UID、命令和 GPU 归属。确认旧监督进程已经退出后，使用 `supervise_existing.py --pid ... --starttime ...` 接管该记录中的 torchrun；参数取对应的 `attempts` 项。该入口持有相同的工作区锁，并自动验证两个训练 rank。常规恢复入口继续用于训练已退出的情况。

第 3,000 步后 `anneal/dense_bias` 显示为字符串 `-inf`，代表 compact 读取模式；loss 与 gradient 的有限性继续独立检查。修复过程见 [监督进程修复](14_监督进程修复.md)。
