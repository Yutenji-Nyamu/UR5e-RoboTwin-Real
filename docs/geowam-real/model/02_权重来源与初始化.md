# 权重来源、放置位置与初始化

路径相对服务器工作区；具体修订版本和哈希见 [sources.lock.json](../sources.lock.json) 及 [初始化记录](../09_INITIALIZATION.md)。

| 用途 | 来源 | 本地路径 |
|---|---|---|
| Video／Action／状态网络 | [OpenWAM-Alpha Real Single Arm Franka](https://huggingface.co/OpenWAM/OpenWAM-Alpha-Real-Single-Arm-Franka) | `models/alpha-franka/checkpoint_step_9860.safetensors` |
| VAE／UMT5／tokenizer | [Wan2.2 TI2V-5B Diffusers](https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B-Diffusers)，通过对应 [ModelScope 镜像](https://modelscope.cn/models/Wan-AI/Wan2.2-TI2V-5B-Diffusers) 获取模块 | `models/wan22-ti2v-5b/` |
| 分割 | [facebook SAM 3.1 ModelScope](https://modelscope.cn/models/facebook/sam3.1) | `models/sam3.1/sam3.1_multiplex.pt` |
| 光流 | [torchvision RAFT-Large 官方权重](https://download.pytorch.org/models/raft_large_C_T_SKHT_V2-ff5fadd5.pth) | `models/raft/raft_large_C_T_SKHT_V2-ff5fadd5.pth` |
| 方法实现 | [MetisWAM4D Gitee](https://gitee.com/droliven/MetisWAM4D_260921) | `repos/MetisWAM4D/`，固定 `1392ab5` |

Video 直接继承 Alpha 中的 Wan 专家。Action 与状态投影也来自同一 Alpha。Track 按作者 `interpolate_from_video` 复制兼容张量并插值调整形状：203 项复制、354 项变形、23 项默认初始化。新增 Focus、角色和进度等模块沿用作者初始化。

Alpha 原有 EEF10 机器人接口，本轮使用 UR5e joint7；网络权重提供起点，新的状态／动作映射通过实测数据适配。作者专用 Track 权重的经验在这轮从初始化与实测监督继续学习。

下载脚本：[fetch_alpha_resumable.py](../../../scripts/geowam/fetch_alpha_resumable.py)、[fetch_alpha_parallel.py](../../../scripts/geowam/fetch_alpha_parallel.py)、[fetch_processing_models.py](../../../scripts/geowam/fetch_processing_models.py)、[fetch_wan_modelscope.py](../../../scripts/geowam/fetch_wan_modelscope.py)。加载形状检查：[audit_init_shapes.py](../../../scripts/geowam/audit_init_shapes.py)。

SAM 文件与上游哈希核对，Alpha／Wan／RAFT 均保留下载与校验记录。模型文件放服务器模型目录，Git 保存来源与加载方式。
